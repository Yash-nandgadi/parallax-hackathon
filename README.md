🚀 Parallax Hackathon

A security-focused project featuring a FastAPI backend, Streamlit dashboard, automated patch management, and security testing scripts.

📂 Project Structure

parallax-hackathon/
│
├── app.py              # Vulnerable/Secured FastAPI backend fixture
│
├── dashboard.py        # Streamlit control center and UI dashboard
│
├── patcher.py          # Automated patch application and reversion logic
│
├── exploits.py         # Automated security testing scripts
│
├── run_demo.bat        # One-click environment setup and launcher
│
└── requirements.txt    # Project dependencies

🛠️ Technologies Used

- Python
- FastAPI
- Streamlit

⚙️ Setup & Installation

1. Clone the repository.
2. Install the required dependencies:

pip install -r requirements.txt

3. Run the demo using:

run_demo.bat

✨ Key Features

- FastAPI backend
